# @semantic-md/react

React renderer and streaming hook for Semantic Markdown.

```bash
pnpm add @semantic-md/react react react-dom
```

```tsx
import { SemanticMarkdown } from "@semantic-md/react";

<SemanticMarkdown content="# Hello" protocol={protocol} />;
```

See the [repository documentation](https://github.com/anisorphcia/custom-md#readme).
